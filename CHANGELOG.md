# Changelog

## 0.2.0 - 2026-10-30

First public release.

- Storage capacity up to 1000 (default 1000, configurable 400-1000).
- Enabled saves keep 400 slots without the mod (upgrade level raised to 17).
- Butch's regular storage reward stops at level 17 in enabled saves, keeping
  the grid within Improved Inventory's 20-column limit.
- Per-slot activation (`Slots=`), detected from the save file the game opens.
- Exact build check (Steam 25143593); otherwise the mod stays off and warns.
- Tested on the author's machine with Improved Inventory 0.3.7: Storage beyond the
  vanilla capacity, save/reload, and a session without the mod.
